# История изменений FW-NetPulse

Все заметные изменения проекта перечисляются в этом файле.

## [1.1.2.0] - 2026-08-28

### Исправлено

- Один клик по карточке игрового окна теперь сразу выбирает соответствующий PID и его сетевые показатели.
- Карточки больше не используют заблокированные политикой безопасности встроенные `onclick`-обработчики.
- Обычное нажатие мыши больше не показывает ложное сообщение о копировании текста.
- Обновление телеметрии не пересоздаёт карточки процессов, поэтому клик и выделение текста не сбрасываются.
- Измеритель зеркала, который не смог запуститься, удаляется из пула и может корректно запуститься при следующей попытке.
- Устаревший фоновый скан больше не возвращает мониторинг на предыдущее окно после ручного выбора.
- PID выбранного окна и активный сетевой адрес меняются атомарно, поэтому при ошибке запуска измерителя они не расходятся.
- Запуск и остановка измерителей сериализованы, а Smart MTR закрывает Win32 ICMP-дескриптор только после завершения рабочего потока.
- Win32-функции кнопки «глаз» получили корректные 64-битные прототипы для надёжной активации окна на Windows x64.

## [1.1.1.0] - 2026-08-25

### Добавлено

- Сохраняемые настройки видимости основного графика, мини-графиков, карточек окон, оптимизатора, Smart MTR и журнала.
- Сворачивание отдельного мини-графика без скрытия остальных окон.
- Кнопка с глазом для восстановления и вывода выбранного игрового окна на передний план.

### Исправлено

- Зеркала на новых портах, включая `29003`, автоматически получают собственный измеритель и график.
- Выделенный текст больше не исчезает: обновление интерфейса приостанавливается на время копирования.
- Мини-графики полностью удаляются из интерфейса, когда игровые процессы закрыты.

## [1.1.0.0] - 2026-08-25

### Добавлено

- Отдельные графики для каждого найденного окна игры с общей шкалой 1, 5, 10 и 15 минут.
- Независимые ICMP-, TCP- и Smart MTR-измерения для каждого уникального игрового зеркала.
- Ручные вкладки игровых окон над таблицей Smart MTR и журналом микрофризов.
- Фильтрация событий SQLite по `IP:порт` и автоматическое обновление старой базы без удаления истории.
- Многоклиентский визуальный тест с четырьмя окнами и четырьмя разными входами.

### Улучшено

- Окна на одном зеркале переиспользуют измерения, поэтому не создают лишний сетевой трафик.
- Закрытые неактивные зеркала автоматически освобождают фоновые службы через минуту.
- Выбор карточки игрового процесса сразу переключает основные показатели на его адрес.
- Соединения SQLite теперь гарантированно закрываются после каждой операции.

## [1.0.0.0] - 2026-08-25

### Добавлено

- Первая публичная версия исходного кода и переносимая сборка для Windows x64.
- Автоматический поиск окон `pem.exe`, `pemv.exe`, `elementclient.exe` и `patcher.exe` с определением активного игрового TCP-адреса.
- Параллельные измерения ICMP и TCP, Smart MTR, журнал сетевых фризов и экспорт CSV/JSON.
- Спокойные графики на 1, 5, 10 и 15 минут с медианным объединением точек, отдельными скачками и красными отметками реальных потерь.
- Точечные профили DPI-обхода только для найденных игровых IPv4-адресов и портов.
- Поддержка заранее настроенных WireGuard-релеев с обязательным маршрутом `/32` только к игровому серверу.
- Калибровка прямого соединения, DPI-профилей и релеев по медиане, P95, джиттеру и потерям.
- Автономная Chart.js: графики работают без доступа к внешнему CDN.

### Исправлено

- Управляющие запросы локальной панели защищены от вызова со сторонних сайтов.
- Ошибки API возвращаются как понятный JSON, поэтому интерфейс больше не показывает `Unexpected token '<'`.
- Повторная сборка не переносит в релиз личную базу истории и старые файлы.
- HUD читает и сохраняет настройки рядом с EXE и учитывает порт из `config.json`.
- При выборе соединения игра получает приоритет перед служебными TCP-подключениями процесса.
