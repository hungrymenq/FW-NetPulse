# Анализ и оптимизация игрового маршрута

FW-NetPulse различает несколько причин плохой связи: домашняя сеть, проблемный
транзитный узел, конечный сервер и возможная фильтрация игрового TCP-трафика.
Предложение программы — это подсказка по измерениям, а не гарантия причины.

## Точечный обход DPI

1. Запустите `FW-NetPulse.exe` от имени администратора.
2. Запустите игру и дождитесь, пока программа определит её IP и TCP-порт.
3. В блоке «Точечный DPI-обход» выберите профиль. Начинайте с
   «Аккуратное разделение TCP».
4. Нажмите «Включить», подтвердите действие и переподключитесь к серверу игры.
5. Подождите не меньше 60 секунд и сохраните результат калибровки.
6. Повторите проверку для других профилей. Программа покажет вариант с наименьшей
   задержкой, джиттером и потерями.

Обход ограничен найденным IP игры и портами из `optimizer.game_ports`. В
стандартной конфигурации это порты 29000–29003. Широкое правило 1024–65535 не
используется. При закрытии FW-NetPulse запущенный им процесс обхода
останавливается.

Если антивирус сообщает `WinDivert` или `RiskTool/PUA`, проверьте, что архив
получен из доверенного источника. Компоненты лежат в `tools\zapret`, а условия
их лицензий — в `tools\zapret\LICENSE-ZAPRET-WINDIVERT.txt`.

## Когда нужен игровой релей

Если проблема находится на транзитном участке между провайдерами, DPI-профиль
обычно не поможет. Windows не может вручную выбрать дальнейшие узлы после
шлюза провайдера: этот путь определяется маршрутизацией операторов. Изменить
его можно через промежуточный VPN-сервер в другом датацентре.

Для этого установите официальный WireGuard for Windows и подготовьте отдельный
конфигурационный файл. В нём `AllowedIPs` должен содержать только IP игрового
сервера с маской `/32`, например:

```ini
[Interface]
PrivateKey = ВАШ_ЗАКРЫТЫЙ_КЛЮЧ
Address = 10.20.0.2/32

[Peer]
PublicKey = ПУБЛИЧНЫЙ_КЛЮЧ_РЕЛЕЯ
Endpoint = АДРЕС_РЕЛЕЯ:51820
AllowedIPs = 51.77.68.91/32
PersistentKeepalive = 25
```

Не публикуйте `PrivateKey`. FW-NetPulse специально отклоняет конфигурации с
`AllowedIPs = 0.0.0.0/0`, чтобы случайно не отправить через релей весь интернет.

Добавьте релей в раздел `optimizer.relays` файла `config.json`:

```json
{
  "id": "eu-relay-1",
  "name": "Игровой релей Европа",
  "config_path": "C:\\WireGuard\\fw-game.conf"
}
```

Проверяйте прямое соединение и релей по 60–120 секунд в одинаковых условиях.
Хороший релей должен уменьшать прежде всего потери и скачки, а не обязательно
средний пинг. Для игр с античитом сначала уточните правила игры: некоторые
издатели запрещают изменение или перехват трафика.
